# TPI Metodología de Sistemas II — Rinaudo Julián

Sistema de Gestión de Solicitudes Académicas (aplicación de consola en Java).

Permite registrar solicitudes de estudiantes, clasificarlas por tipo, prioridad y estado,
asignar un responsable, buscar/filtrar solicitudes y generar un reporte básico.

## Requisitos

- Java 21
- Maven 3.9+

## Uso

```bash
mvn package
java -jar target/gestion-solicitudes.jar
```
